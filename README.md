Min bollbok — adresserna bakom QR-koderna. QR-koderna i boken pekar hit: sandstenmattias-stack.github.io/b/01 och så vidare. Adressen är tryckt i böckerna och går aldrig att ändra, men vart den skickar barnet vidare går att ändra när som helst. Hela adresstabellen ligger i 404.html. Öppna den filen, tryck på pennan, leta upp kodens rad och byt YouTube-adressen. Fyra koder väntar på innehåll: b/44, b/45, b/46 och b/jul. De visar en kommer snart-sida så länge.
